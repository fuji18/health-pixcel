# 要求内容

## 概要

歩数・睡眠時間の日別推移を棒グラフで表示する。選択中の表示期間(7 日 / 30 日)に合わせて描画する(Issue #21)。

## 背景

PRD P1「グラフによる推移の可視化」。今の画面は日別の一覧だけで、数日〜1 か月の傾向を一目で掴みにくい。グラフライブラリは `fl_chart`(^1.2.0)に確定済み(`docs/architecture.md`「フレームワーク・ライブラリ」)。

## 実装対象の機能

### 1. 推移グラフ(歩数・睡眠時間)
- 睡眠セクション・歩数セクションのそれぞれで、一覧の上に日別の棒グラフを表示する
- 期間を 7 日 / 30 日で切り替えると、グラフも同じ日数で描き直される
- 記録なしの日は棒を出さない。記録のある日(値が 0 でも)とは形で区別できる
- スクリーンリーダーでは、グラフ全体の要約(日数・記録のある日数・平均・最大)が 1 回で読み上げられる

### 2. 依存の追加
- `pubspec.yaml` に `fl_chart: ^1.2.0` を追加する(`fl_chart` を import するのは `lib/presentation/` 配下だけ)

## 受け入れ条件

### 推移グラフ
- [ ] 7 日 / 30 日の両方で、歩数・睡眠の両セクションにグラフが表示される
- [ ] 記録なしの日は棒も下地も描かれず、記録のある日と区別できる
- [ ] 全日記録なしのときはグラフの代わりに「この期間の記録はありません」を表示する
- [ ] グラフのウィジェットテスト(データあり / 一部記録なし / 全日記録なし)がある
- [ ] `docs/functional-design.md` の UI 設計を更新する

### 依存の追加
- [ ] PR 本文に、`fl_chart` とその推移的依存に通信・解析 SDK が無いことの確認結果がある
- [ ] CI のリリースビルドと権限検査(`INTERNET` の不在)が緑
- [ ] リリース APK サイズが目安(30MB)を大きく超えていない

## 成功指標

- 期間を切り替えたとき、数日〜1 か月の傾向がスクロールせずにグラフで掴める

## スコープ外

以下はこのフェーズでは実装しません:

- 目標ライン(#23)
- 心拍・体重・運動のグラフ(#24〜#26)
- グラフのタップ操作(ツールチップ)・アニメーション(正確な値は一覧で見られる)
