# 要求内容

Issue: #23 [チケット] 目標の達成状況の表示(P1 / フェーズ 3 / depends: #21, #22)

## 背景・目的

PRD P1「目標設定と達成状況の表示」の後半。#22 で保存した目標に対して、日別の達成状況をダッシュボードに表示する。

## スコープ(やること)

- 日別リストの各日に達成 / 未達のマークを付ける(記録なしの日は判定しない)
- 推移グラフ(#21)に目標ラインを引く
- 目標が未設定なら、マークもラインも出さない

## スコープ外(やらないこと)

- 達成率の集計・連続達成日数など(P2「週次の振り返りサマリー」で扱う)
- 目標値の入力・保存の変更(#22 で完了)

## 受け入れ条件

- [ ] 達成 / 未達 / 記録なし / 目標未設定がそれぞれ区別して表示される(色だけに頼らない)
- [ ] 達成判定のロジックはドメイン層にあり、ユニットテスト(境界値: 目標ちょうど)がある
- [ ] 目標を変更して戻ると、表示が即座に反映される
- [ ] `docs/functional-design.md` を更新する

- `docs/product-requirements.md`「将来的な機能(Post-MVP) > P1」
- `docs/functional-design.md`「表示項目」「推移グラフ」「カラーコーディング」
- `docs/ui-design-guidelines.md` §6
