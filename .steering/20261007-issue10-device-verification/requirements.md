# 要求: MVP の実機検証とリリース確認(#10)

## 背景・目的

MVP を Pixel 10 実機で受け入れ確認し、PRD のセカンダリーKPI(表示の正確さ・外部送信ゼロ)と非機能要件(3 秒以内の表示)を満たすことを確かめる。

## 担当の分け方

- **実機での操作・計測・目視(Windows 側)**: 人間。devcontainer には Android SDK も端末も無いため、Claude は実行できない
- **手順の用意・結果の判定・docs への反映・不具合の振り分け**: 司令塔(Claude)
- 結果は `results.md` に記録する(このディレクトリ)

## スコープ

- `docs/functional-design.md`「テスト戦略 > 実機確認(Pixel 10、手動)」の全 7 項目の実施と記録
- HUAWEIヘルスケアとの 7 日分の突き合わせ(歩数・睡眠)
- コールドスタートから表示までの時間・再読み込みの時間の計測
- PRD「未確定事項」の睡眠時間の定義の結論を docs に反映
- 確認で見つかった小さい不具合の修正(大きいものは別チケットに切り出す)

## スコープ外

- P1 / P2 の機能
- 計測用のコード(タイマーやログ)をアプリに足すこと(外部計測で足りる。ログ出力はプライバシー要件と衝突しやすい)

## 受け入れ条件(Issue #10 より)

- [ ] 実機確認チェックリストの全項目が記録されている
- [ ] 7 日分の歩数・睡眠が HUAWEIヘルスケアの表示と一致する(差異は原因とともに記録)
- [ ] 起動から表示まで 3 秒以内(権限許可済み・コールドスタート)、再読み込みは 2 秒以内
- [ ] `check-release-permissions.sh` が `exit 0`、APK Analyzer で `INTERNET` が無いことを目視確認
- [ ] `adb logcat` に歩数・時刻・睡眠時間の値が出ていない
- [ ] PRD「未確定事項」の睡眠時間の定義の結論を docs に反映
